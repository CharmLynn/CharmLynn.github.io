SaveAnswer Privacy Policy

Last updated: 2026-10-10

Data storage

Everything you save with SaveAnswer — questions, answers, tags and source links — is stored locally in your browser through chrome.storage.local. It is never uploaded to a server.

No data collection

  • No account is required.
  • The extension contains no analytics, tracking or telemetry code and sets no cookies.
  • Saved answers are never sent anywhere.

Pages the extension can open

  • Uninstall survey. When you remove SaveAnswer, the browser opens a one-question survey page on this site. The page address contains only your UI language and the extension version.
  • Feedback page. The "Feedback" link in the popup opens a form on this site, with the same two values in the address.

Both forms are optional. If you submit one, only what you type, the extension version and your browser type are sent, so we can read and reply to it. Nothing from your saved library is included.

Permissions

  • storage: to keep your saved answers and settings locally.
  • Access to supported AI chat sites: to add the Save button and read the single answer you choose to save.

Contact

Questions about privacy: feedback page.

SaveAnswer 隐私政策

更新日期：2026-10-10

数据存储

你用 SaveAnswer 保存的所有内容（提问、回答、标签、来源链接）都通过 chrome.storage.local 保存在你自己的浏览器里，不会上传到任何服务器。

不收集数据

  • 不需要注册账号。
  • 扩展里没有统计、追踪或遥测代码，也不设置 Cookie。
  • 保存的回答不会被发送到任何地方。

扩展可能打开的页面

  • 卸载问卷：卸载 SaveAnswer 时，浏览器会打开本站的一个单题问卷页，网址里只带界面语言和扩展版本号。
  • 反馈页：弹窗里的「反馈建议」链接会打开本站的反馈表单，网址里同样只带这两个值。

两个表单都可以不填。如果你提交了，发送的只有你填写的内容、扩展版本号和浏览器类型，用于阅读和回复，不包含你保存库里的任何内容。

权限说明

  • storage：在本地保存你的回答和设置。
  • 访问支持的 AI 对话网站：在页面上加入保存按钮，并读取你选择保存的那一条回答。

联系方式

隐私相关问题请通过 反馈页 联系。
