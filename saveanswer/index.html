常见问题解答与深度指南 Frequently Asked Questions

关于 420px 弹窗与桌面工作台双模式、数据隐私安全性、本地知识库同步与免费承诺的解答。 Everything you need to know about the dual-tier workflow, local storage privacy, Obsidian sync, and free commitment.

420px 侧边轻弹窗和三栏全屏桌面工作台，分别在什么时候使用？When should I use the 420px popup versus the 3-column desktop workspace?

420px 侧边弹窗是高频日常使用的第一层场景：在浏览网页或写代码时，随时呼出搜索历史问答、复制已保存的代码片段或临时打标签，无需中断当前工作流；当面对数千字的技术深度推导、多篇跨模型对比、或需要按复杂分类整理长文时，点击弹窗右上角一键跃迁至三栏全屏工作台，享受宽屏语法高亮与多选批量报告导出。The 420px popup is your daily high-frequency touchpoint: search saved answers in-situ, copy syntax-highlighted code snippets, and organize tags without switching windows. When you need deep technical reading, long code analysis, or cross-model report merging, click the top-right button to expand into the 3-column desktop workspace.

和直接使用 ChatGPT 自带的历史搜索有什么区别？How is this different from ChatGPT's own history search?

聊天记录搜索只能按单平台标题检索，且高价值结论深埋在海量闲聊与试错中。SaveAnswer 只收录你明确点过「保存」的有价值资产，跨越 ChatGPT、Claude、DeepSeek、Gemini 放在统一的三栏库中，按问题与回答全文秒级检索。Built-in history covers one platform and mixes good answers with countless throwaway chats. SaveAnswer keeps only the replies you explicitly pick, across ChatGPT, Claude, DeepSeek and more, in one full-text-searchable desktop library.

我的数据真的不会上传到任何服务器吗？Are my answers truly stored locally?

绝无任何上传。所有内容直接保存在当前浏览器的 chrome.storage.local 与你授权的本地目录中。没有后台服务器，没有用户分析与追踪代码，无需注册登录，扩展甚至不申请除目标 AI 域名之外的跨域网络权限。Zero servers. All saved answers live in your browser's local storage and your authorized local disk folder. There is no cloud backend, no telemetry, and no accounts required.

如何与 Obsidian 和 AI Coding Agent（Cursor 等）联动？How does it sync with Obsidian and AI Coding Agents?

在扩展中点击「Obsidian」面板，授权你本地的知识库文件夹（如 SaveAnswer/）。每次保存问答时，扩展会直接通过浏览器底层 File System Access API 写入标准 Markdown 文件（附带完整 YAML Frontmatter）。Cursor、Claude Code 或 Cline 可直接通过 @Docs 或上下文规则将该目录作为私域经验库进行索引！Authorize your local notes directory via File System Access API. SaveAnswer writes atomic Markdown files with YAML frontmatter directly to disk. Any local agent (Cursor, Claude Code, Cline) can mount this folder as a verified knowledge base!

如果我换电脑或重装浏览器，如何备份与迁移数据？What happens if I switch computers or reinstall Chrome?

v1.2.0 工作台内置完整的「全量 JSON 备份导出」与「一键去重合并导入」功能，换机迁移只需几秒钟；同时在任意 AI 输入框按 Alt+K 可随时原地召回历史保存内容，或开启本地目录同步将 Markdown 直接保存在硬盘中。v1.2.0 includes full JSON Backup & Deduplicated Import in the workspace for effortless device migration, Alt+K in-chat prompt recall across models, plus direct-to-disk local Markdown folder sync.

是否收费？后续会有付费版本吗？Is SaveAnswer free?

SaveAnswer 是一个 100% 免费、本地优先的个人生产力工具。没有 Token 订阅制、没有付费会员墙，核心功能始终无保留开放给全球开发者与研究人员使用。Yes, 100% free and local-first. No paid tiers, no token paywalls, and no subscription traps.
