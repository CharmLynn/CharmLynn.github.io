第一步：授权本地目录（零云端直写）

安装 SaveAnswer 后，点击扩展顶部文件夹图标选择你的本地 Obsidian 库或工程文档目录。每次在 8 大 AI 网页点击 Save（或 Alt+点击 极速保存），扩展会通过浏览器原生 File System Access API 写入带标准 YAML Frontmatter 的 .md 文件，并自动更新目录索引 SaveAnswer/INDEX.md。

第二步：复制下方 Obsidian Dataview 自动看板模板

在你的 Obsidian 库新建一篇 AI 知识中枢.md，粘贴以下 Dataview 查询代码，所有跨模型保存的回答会自动按日期与标签聚合：

```dataview
TABLE WITHOUT ID
  file.link AS "问题 / 主题",
  source AS "来源模型",
  tags AS "标签",
  date AS "沉淀时间"
FROM "SaveAnswer"
WHERE file.name != "INDEX"
SORT date DESC
LIMIT 50
```
