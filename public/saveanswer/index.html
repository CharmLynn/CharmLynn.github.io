零开发 Agent MCP 是怎么把本地知识库接进 Cursor / Claude Code 的？How does Zero-Dev Agent MCP work without installing a custom server?

SaveAnswer 2.0 通过浏览器原生 File System Access API，把你保存的问答写成标准的本地 Markdown 文件（附带 YAML Frontmatter 和自动目录 INDEX.md）。点击工作台右上角 Agent MCP，输入你的本地目录路径，即可一键生成 Anthropic 官方开源 @modelcontextprotocol/server-filesystem 的 JSON 配置——粘贴进 ~/.cursor/mcp.json 或 Claude Desktop 即可直接检索你的历史 AI 问答！SaveAnswer 2.0 writes clean, idempotent Markdown notes (with YAML frontmatter + INDEX.md) directly to your local folder via the browser's File System Access API. Clicking Agent MCP generates the standard @modelcontextprotocol/server-filesystem JSON config pointing to that folder—paste it into ~/.cursor/mcp.json or Claude Desktop with zero custom daemon required.

SaveAnswer 2.0 支持哪些全局快捷键？What keyboard shortcuts are built into SaveAnswer 2.0?

Alt+S：免鼠标盲存当前页面最新一条 AI 回答；Alt+W：随时一键呼出三栏桌面工作台；Alt+K：在任意 AI 聊天输入框内呼出原地召回面板，搜索并插入已存 Markdown；在浏览器地址栏输入 sa 关键词 还可跨标签页全局秒搜。Alt+S saves the latest AI answer without touching the mouse; Alt+W opens the 3-column desktop workspace; Alt+K opens In-Chat Quick Recall inside any AI chat box; and typing sa + keyword in the browser address bar searches your library from any tab.

我的数据真的不会上传到任何服务器吗？Are my answers truly stored locally?

绝无任何上传。所有内容仅保存在当前浏览器的本地存储与你主动授权的本地目录中。无云端后台、无用户追踪、无账号登录，扩展仅声明 storage、unlimitedStorage 与 8 个目标 AI 网站权限。Zero servers, zero cloud sync, zero telemetry, and no accounts. All answers live strictly inside your browser's local storage and the local folder you authorize.

换电脑或存了很多条之后，怎么备份、迁移和清理？How do I back up, migrate across devices, or clean up old items?

工作台左下角内置实时存储监控与 Backup / Import / Manage 工具：支持一键全量 JSON 备份、换机去重合并导入、以及按 30 天 / 90 天安全归档清理（若未手动备份，清理前会自动为你下载一份 JSON 安全备份）。The workspace footer includes a live storage meter plus Import, Backup, and Manage controls: export lossless JSON or Markdown archives, merge-import backups on a new machine without duplicates, and clean older entries with an automatic safety backup.
