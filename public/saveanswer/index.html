答疑解惑 · 常见问题FAQ & Architecture Notes

常见问题解答与深度指南 Frequently Asked Questions

关于收藏与查看答案、弹窗与工作台双模式、本地隐私、Obsidian & MCP 联动与备份迁移的解答。 Everything you need to know about saving & viewing answers, local storage privacy, Obsidian + MCP sync, and backups.

420px 侧边轻弹窗和三栏全屏桌面工作台，分别在什么时候使用？When should I use the 420px popup versus the 3-column desktop workspace?

420px 弹窗是高频日常查看答案的第一入口：浏览网页或写代码时点一下图标（或在地址栏输入 sa 关键词），即可秒搜历史问答、复制代码或跳回原对话；当需要阅读数千字长文、按平台与标签系统整理、或跨多条答案对比复盘时，点击弹窗右上角（或按 Alt+W）展开三栏全屏工作台，享受宽屏语法高亮与舒适/紧凑双视图阅读。The 420px popup is your everyday quick lookup: search saved answers from any tab (or type sa in the address bar), copy code snippets, and jump back to original chats. When reading long technical replies or organizing tags across platforms, click expand (or press Alt+W) to open the 3-column full-page workspace.

和直接使用 ChatGPT / DeepSeek 自带的历史记录搜索有什么区别？How is this different from built-in chat history search?

自带历史记录只能搜单一平台，而且真正有用的结论深埋在大量闲聊与试错里。SaveAnswer 只收录你明确点过「保存」的精选回答，把散落在 8 个平台的优质答案统一收进一个库里，支持按问题、正文、平台和标签秒级检索，点击还能直接滚回原对话那一条回答的位置。Built-in history covers only one site and buries great answers under hundreds of throwaway threads. SaveAnswer keeps only the replies you explicitly save across 8 AI platforms in one unified, full-text-searchable library—with message-level jump-back.

如何与 Obsidian 以及 Cursor / Claude Code（MCP）联动？How does it sync with Obsidian and AI Coding Agents via MCP?

在扩展中授权你的本地笔记文件夹（如 SaveAnswer/），每次收藏回答都会自动写入带 YAML 元数据的标准 Markdown 文件并更新 INDEX.md，Obsidian 打开即用。若想接入编程助手，点击工作台右上角「Agent MCP」即可一键复制标准 @modelcontextprotocol/server-filesystem JSON 配置，粘贴到 Cursor 或 Claude Desktop 即可直接检索你的本地问答库。Authorize a local folder via the browser's File System Access API to write clean Markdown files + INDEX.md directly into your Obsidian vault. To connect coding agents, click Agent MCP in the workspace to copy a standard @modelcontextprotocol/server-filesystem config for Cursor or Claude Code.

我的数据真的不会上传到任何服务器吗？Are my answers truly stored locally?

绝无任何上传。所有收藏内容仅保存在当前浏览器的本地存储与你主动授权的本地文件夹中。没有后台服务器，没有用户追踪，无需注册登录，扩展仅声明目标 AI 网站与本地存储权限。Zero servers. All saved answers live strictly in your browser's local storage and the local folder you authorize. No cloud backend, no telemetry, and no accounts required.

换电脑或存了很多条之后，如何备份、迁移与管理空间？How do I back up or migrate my library across computers?

工作台左下角提供实时本地存储显示以及备份 / 导入 / 清理工具：支持一键导出整库 JSON 备份并在新电脑上去重合并导入，也支持批量导出 Markdown 归档；清理旧条目时若未备份还会自动下载安全备份文件。Use the storage bar in the bottom-left of the workspace to export a full JSON backup, merge-import onto a new machine without duplicates, export Markdown archives, or safely archive older items.

是否收费？MCP 和整页工作台功能收费吗？Is SaveAnswer free?

100% 免费，永久本地优先。没有订阅制、没有付费会员墙，从一键收藏、三栏工作台查看，到 Obsidian 同步与 Agent MCP 全部免费开放。Yes—100% free and local-first. No subscriptions, no paywalls, and every feature from 1-click saving to the full workspace and MCP config is free.
